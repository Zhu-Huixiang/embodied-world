# 受辅助的障碍路线不作速度倍数 · Perceptive Locomotion

预定障碍路径由pure pursuit跟踪；新控制器33秒完成，对照用时75秒且有人抬推帮助。

这组演示显示了卡住和动作连续性的差别，但帮助改变了执行条件，不能把33与75直接算成公平的路线效率提升。

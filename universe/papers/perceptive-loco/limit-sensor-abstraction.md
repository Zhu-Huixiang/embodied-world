# 高度图换来传感器兼容也丢掉外观 · Perceptive Locomotion

高度图让LiDAR和深度相机共用同一策略，同时丢掉部分材料、纹理和遮挡信息。

经典位姿估计和地图构建没有随策略一起训练；直接处理原始感知、理解遮挡以及异常脱困动作仍是进一步研究方向。

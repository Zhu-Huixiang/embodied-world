# 接触与扰动真值只在训练侧可见 · Perceptive Locomotion

50维特权信息由接触状态、力、法向、摩擦、腿部碰撞、外力和外力矩、airtime构成。

教师读取这些值，学生重建任务也用它们作目标；实机并没有为此增加一套可直接报告全部物理真值的传感器。

# 接口通用不消除身体约束 · UMI

复用相对末端表示与相机视角帮助跨臂迁移，但运动学、安装与动力学仍约束可执行动作。

把数据带到更多场景与让任意身体执行任意动作是两件事，论文通过过滤和匹配接口解决前者的一部分。

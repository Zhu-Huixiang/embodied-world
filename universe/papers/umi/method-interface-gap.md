# 示范数据与可部署数据之间的缺口 · UMI

手持工具能采多样动作，但视觉、运动追踪、动作表示和执行时间失配仍可阻止迁移。

UMI的贡献在接口组合：它沿用Diffusion Policy，不把更大的网络当作所有失配的通用补丁。

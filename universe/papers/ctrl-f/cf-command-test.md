# 只改指令，外力轨迹保持一致 · Ctrl-F

同一低层策略分别接收正确、关掉、反向的力指令。

每片段同一外力轨迹重放，覆盖十二片段；满量程正确指令completion约75%，其余三设置含SONIC均不超过30%。反向更差，支持策略确实利用方向和幅值，而非仅做无条件抗扰。

继续拆：[命令30 N，秤读24.5 N](cf-real-force.md)。

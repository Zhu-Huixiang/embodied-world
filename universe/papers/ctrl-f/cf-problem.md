# 动作像，不等于接触力够 · Ctrl-F

同一段参考动作碰到不同负载，需要不同的施力。

论文把全身运动跟踪与物体受力分开：手到指定位置并不保证夹住箱子，接触标签也不指定力的方向和大小。

# CQL 单页架构图规格

目标：读者先看到固定数据如何约束 Bellman 回归，再看到保守项如何修改 critic，最后区分训练策略更新与运行交互。

布局：340×1300 pt 竖版。A 固定数据、B Bellman 拟合、C 动作间校准、D 策略与运行，按正文技术顺序排列。浅青色承载数据与目标，暖色承载保守训练，浅蓝色承载策略。青实线表达依赖或运行反馈；珊瑚红虚线只表达训练更新或训练采样。

每区保留真正的原生生图插画对象，并将公式、关键标签与路径交给独立 TeX/TikZ 层。B+C 更新当前 critic 的返回箭头必须落到 critic，而非目标卡或策略。D 的状态反馈闭环只连接策略与模拟器。连续动作的10+10采样与离散式展示相邻区分。

关键判断：数据动作的抬升是相对于保守压低项；Bellman 拟合仍然同时存在。示意柱高不编码实测值。模拟器场景不暗示实机验证。公式中的下界与误差条件由正文展开。

完整源与论文逐项定位见 `source-notes.md`。

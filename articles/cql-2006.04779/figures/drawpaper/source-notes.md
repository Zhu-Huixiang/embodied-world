# CQL 架构图：图源与科学对应

本图对应 Kumar、Zhou、Tucker、Levine 的 NeurIPS 2020 正式论文 *Conservative Q-Learning for Offline Reinforcement Learning*。

- [正式论文](https://papers.nips.cc/paper_files/paper/2020/file/0d2b2061826a5df3221116a5085a6052-Paper.pdf)，PDF 共 13 页。SHA-256：`98f9e70d85fca8fc095f7327990f29f65decee5a0f671997a831a212bc653d8e`。
- [附录](https://papers.nips.cc/paper_files/paper/2020/file/0d2b2061826a5df3221116a5085a6052-Supplemental.pdf)，PDF 共 18 页，对应印刷页 14–31。SHA-256：`44037fe4ea1e0e70c86a3dfa7e8633b8f4af12f6f6b863d1c379a2c4e9f668f0`。

## 分区与论证定位

| 区域 | 图中输入、运算与输出 | 原文定位 |
| --- | --- | --- |
| A 固定数据 | 从已有转移 `(s,a,r,s′)` 抽样；训练期间不添入新交互。`s` 是状态，`a` 是动作，`r` 是奖励标量，`s′` 是后继状态。 | §2；§4 Algorithm 1 |
| B Bellman 拟合 | 当前价值 `Qθ(s,a)` 是标量；奖励加折扣后继估值构成标量目标 `y`。固定目标进行平方误差回归，只在数据动作上拟合。 | §2；§3.1 Eq. 1–2 |
| C 保守正则 | 在同一数据状态比较候选动作与数据动作。离散 `log-sum-exp` 压低较高估值，减去数据动作平均 Q 使数据动作相对得到支撑；B+C 联合更新 critic 参数 θ。 | §3.2 Eq. 4；§4 Algorithm 1；附录 F 印刷页29 |
| D 策略与运行 | 训练时 critic 指导策略参数 φ；最大化 Q 并保留熵项。当前策略也为 C 提供候选动作。运行时策略根据状态选动作，模拟器返回新状态。 | §4 Algorithm 1；§6 模拟任务 |

## 符号与适用范围

`πφ(a|s)` 是策略分布；`π̂β` 是数据的经验行为动作分布；`α≥0` 控制保守项，`γ` 是折扣因子。图中 `LB` 和 `cH(s)` 是排版用的教学缩写。数据状态及动作的维度由具体任务决定，图不虚构统一网络宽度。神经节点、压杆和柱高是机制插画，不指定作者网络层数，也不构成实验数据。

B 展示论文策略评估用的一步 Bellman 目标；并未把该教学表达声明为实现中完整的 SAC 目标。目标中的期望是给定已采样后继 `s′` 后对后继动作的期望。D 的单位熵系数沿用论文 Algorithm 1 的简写。

C 的显示公式是离散动作式。连续动作时对应动作积分；附录 F 用 10 个均匀样本与 10 个策略样本，通过各自采样密度的重要性权重估计。完整密度除法见文章公式图 `eq09-continuous`，图中“20个样本”不表示直接对20个Q值做无权求和。

红色虚线属于训练：右侧回路把联合目标导回当前 critic；左侧回路表示策略提供候选动作。青色 D 内回路属于运行时状态反馈，没有指回固定数据集。A→B→C→D 是阅读顺序与计算依赖。理论中的期望下界依赖表格或文中近似条件，未被画成神经网络的逐点保证或物理安全保证。

## 重新编译

在本目录运行 `xelatex -interaction=nonstopmode -halt-on-error cql-overview.tex`。需要 XeLaTeX、TikZ、xeCJK、amsmath、Arial 与 macOS Heiti 字体；其他系统可将字体设置替换为可用中文字体。所有插画依赖使用本目录相对路径。随后以 PDF 页为准输出 PNG；公式和连线保持矢量精度。

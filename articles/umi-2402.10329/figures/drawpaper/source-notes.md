# UMI DrawPaper：科学规格、素材保留与渲染核对

## 版本与交付

- 主文：RSS 2024 官方版，`https://www.roboticsproceedings.org/rss20/p045.pdf`，本机 `paper/umi-2402.10329/rss2024.pdf`。
- 附录：作者项目完整版，`https://umi-gripper.github.io/umi.pdf`，本机 `paper/umi-2402.10329/author-project-with-appendix.pdf`；A 说明时延测量、D 说明 SLAM、E 说明策略实现、F 说明硬件。
- 训练背景：Diffusion Policy 原文 `https://arxiv.org/abs/2303.04137`，所读本地 arXiv v1，§II-C Eq.(5)。本文采用标准噪声预测教学展开，不把它写成 UMI 新损失或 UMI 原编号公式。
- 总图 `umi-architecture.{tex,pdf,png}` 为 **位图插画 + 独立 TikZ 标签、公式和外部连线的混合排版**。时延细图 `umi-timing-mobile.{tex,pdf,png}` 为独立矢量精排。
- `umi-imagegen-draft.png` 为实际内置生图草稿，原件不变；`imagegen-prompt.md` 保留实际提示词。草稿中的错误运行箭头没有被用于终稿。
- 每个 PDF 都只有一页；画布 340 bp 宽，主要文字 14 pt，辅助文字 13.5 pt。在 335 px 显示宽度约为 13.7 / 13.3 px；数学上下标依 TeX 规则更小。正文可点开高清图片与 PDF。

## 科学覆盖表

| 原文定位 | 图中位置 | 输入 → 运算 → 输出 / 作用 | 边界与符号 |
| --- | --- | --- | --- |
| 主文 HD1、HD2，Fig.2、Fig.4 | A | 人手操作带 GoPro、侧镜和软指的夹爪；RGB 与内置 IMU 随 MP4 记录 | GoPro RGB/IMU 是采集侧记录；无触觉、力、语音策略输入。鱼眼图像与侧镜提供视觉线索；不生成显式 depth map。 |
| HD3–HD5；附录 B、D | B 上半与插画 | RGB + IMU 经离线视觉惯性 SLAM 得到米制位姿；指间标记给连续夹爪宽度；同场景地图提供双臂相对位姿标签 | SLAM 是离线动作标签恢复，部署策略没有 SLAM 输入。重定位以后继续 SLAM 优化，图没有冻结地图的含义。 |
| PD2、Fig.6 | B 公式；C 条件 / 输出 | 以本次策略起点作相对坐标，输出未来相对位姿与宽度序列 | `T_0` 与 `T_t` 是同一参考系中的末端刚体位姿，`ΔT_(0→t)=T_0^(-1)T_t` 为原文描述的 SE(3) 数学展开。所有未来姿态共用 `T_0`；不是逐步 delta 累加。齐次矩阵的 4×4 数学表示不等于网络输出维数。 |
| HD6 | B 底部 | 已知目标机器人的运动学与基座关系，离线过滤不可行示范轨迹 | 过滤并不单独保证全部运行时动作可行。 |
| 主文 V-A；附录 Table A1；DP §II-C Eq.(5) | C | 图像、相对末端位姿和夹爪宽度历史构成条件 `c`；双臂另加入相对夹爪位姿。对动作加噪，再监督噪声预测并更新策略；推理从随机噪声逐轮去噪得到动作序列 | `A^(k)` 为扩散第 `k` 步的含噪动作序列，`ε` 为所加噪声，`ε_θ(A^(k),k,c)` 为条件噪声预测器，`θ` 为可训练参数；图中平方范数是单样本教学损失，训练取样本平均 / MSE。未假定未知动作维数，也未把 `T_a=6` 说成完整预测序列长度。 |
| PD1、Fig.5；附录 A1–A2 | D 首两行；时延细图 1 | 测量各观测流时延，按图像拍摄时刻 `t_obs` 对本体反馈历史插值，组合同一时刻的观测条件 | 不把图像传到主机的时刻当拍摄时刻；双臂图像近邻软同步细节由正文展开。运行本体反馈来自机器人臂 / 夹爪，不来自 SLAM。 |
| PD1、Fig.5；附录 A3–A4 | D 后两行；时延细图 2–3 | 策略预测从最新观测 `t_obs` 起的未来；每类硬件删去来不及执行的目标，按 `t*−ℓ_h` 提前发送，目标共同在 `t*` 到达 | `ℓ_h` 为硬件 `h` 的实测执行延迟；图形位置仅说明相对先后，没有实验数值或等比例时间含义。推理耗时计入目标是否过期。 |
| PD1 与整体系统闭环 | D 环境到观测的回箭头 | 环境变化 → 下一轮腕部 RGB 与机器人本体反馈 → 策略 → 调度 → 臂 / 夹爪 → 环境 | 独立重建草稿中错误的 controller-to-camera 连线；回箭头到观测行，不接相机命令输入。 |

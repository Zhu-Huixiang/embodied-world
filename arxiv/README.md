## 每日收集的步骤

1. 查询 cs.RO，以及 cs.CV / cs.AI / cs.LG 中与机器人、世界动作模型、运动控制有关的新稿。保留源健康与抓取时间。
2. 合并 arXiv 基础ID与版本，排除未来日期。题目/摘要只负责入队。
3. 初读方法、实验和原文首页署名：贡献要具体，比较对象和任务要能定位；证据不足的工作留待核。
4. 选入的论文进入统一论文库、地图与具身榜，完整解读另按编辑日程推进。

# ICLR｜International Conference on Learning Representations

## 这是什么刊会

学习表征与深度学习；包括生成建模、强化学习和控制方法。

评审与出版：主会研究论文同行评审；正式主会论文集是本目录的归档依据。ICLR 使用 OpenReview 公开评审与讨论。

## 含金量与领域定位

学习表征和深度学习方法的重要主会，公开讨论可帮助跟踪方法争议。

下面把目录事实、计量快照与编辑判断分开列出。核对日期：2026-10-10。

| 指标 | 本版记录 |
| --- | --- |
| CCF | A 类；2026目录，第57页 |
| JIF / SCI / 分区 | 会议不套用期刊影响因子、SCI或JCR/中科院分区 |
| 社区定位编辑分 | 95 / 100；编辑对领域定位的判断，非官方等级或口碑调查 |
| 本版刊会分 | 95.0 / 100；参与具身榜30%权重 |

主会与 workshop 各自归档；oral、poster 是展示形式，不能另当一个刊会等级。

# An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

正式出处：International Conference on Learning Representations 2021。

[原文页面](https://iclr.cc/virtual/2021/poster/3013) · [原文 PDF](https://arxiv.org/pdf/2010.11929v2) · [阅读卡片](../../../library/vit.md)

研究范围：生成/表征基础，机器人视觉编码器与 VLA 图像 token 的入口。

ICLR 2021 正式论文；此条对应原始 ViT，不将后来的自监督或机器人结果算作本篇实验。

阅读问题：一张图怎样变成 token 序列，机器人策略拿到的视觉特征来自哪一步？

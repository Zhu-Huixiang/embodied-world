# Attention Is All You Need

正式出处：Conference on Neural Information Processing Systems 2017。

[原文页面](https://papers.nips.cc/paper/2017/hash/3f5ee243547dee91fbd053c1c4a845aa-Abstract.html) · [原文 PDF](https://papers.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf) · [阅读卡片](../../../library/attention.md)

研究范围：生成/表征基础，VLA、动作 Transformer 与视频模型共用的注意力计算。

正式出处为 NIPS 2017（现名 NeurIPS）；保留原始会议论文，机器翻译实验与后续机器人应用分开。

阅读问题：Q、K、V 到底在计算什么，为什么这套序列计算能连接视觉、语言和动作？

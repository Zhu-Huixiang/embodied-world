# NeurIPS｜Conference on Neural Information Processing Systems

## 这是什么刊会

机器学习与计算神经科学交叉；包括生成、序列建模、学习与决策。

评审与出版：主会研究论文同行评审；正式主会论文集是本目录的归档依据。

## 含金量与领域定位

机器学习主要主会；序列生成结果和真实机器人证据需要分别读。

下面把目录事实、计量快照与编辑判断分开列出。核对日期：2026-10-09。

# Nature

## 这是什么刊会

综合科学期刊，面向跨领域科学读者；本仓从世界模型工作读跨任务的共同结论。

评审与出版：编辑筛选后进行同行评审；研究论文、评论和新闻等文章类型分别核对，不能仅凭刊名判断文种。

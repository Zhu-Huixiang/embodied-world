# PaLM-E: An Embodied Multimodal Language Model

研究范围：连续感知到语言空间的具身多模态推理与高层操作规划。

收录 ICML 2023 正式版。PaLM-E 产生文字计划，勿混写成 RT-2 式直接动作 token 策略。

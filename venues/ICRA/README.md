# ICRA｜IEEE International Conference on Robotics and Automation

## 这是什么刊会

机器人与自动化：控制、感知、规划、操作、机构设计与系统。

评审与出版：IEEE RAS 机器人会议；研究论文经同行评审，正式论文集通常由 IEEE Xplore 收录。

## 含金量与领域定位

机器人领域覆盖广、长期积累强的主要会议；机器人社区定位与CCF计算机目录的B类并列解释。

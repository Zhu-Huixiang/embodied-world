# TMLR｜Transactions on Machine Learning Research

## 这是什么刊会

机器学习方法与表征研究。

评审与出版：滚动投稿、双盲评审，OpenReview公开评审过程；强调技术正确性与研究论证。ISSN 2835-8856。

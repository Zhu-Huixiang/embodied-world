# ICCV｜IEEE/CVF International Conference on Computer Vision

## 这是什么刊会

计算机视觉方法、表征、三维与生成建模；通常两年举办一次。

评审与出版：主会研究论文同行评审；正式主会论文集是本目录的归档依据。

## 含金量与领域定位

视觉领域主要主会；DiT 等图像生成基础为后续视频动作架构提供前置知识。

下面把目录事实、计量快照与编辑判断分开列出。核对日期：2026-10-09。

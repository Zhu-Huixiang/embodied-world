# RSS｜Robotics: Science and Systems

## 这是什么刊会

机器人科学与系统；覆盖感知、规划、控制、学习与真实机器人。

评审与出版：主会研究论文同行评审，征稿说明对问题、技术贡献与实验论证的要求。

## 含金量与领域定位

机器人核心研究社区的重要主会；本仓优先看方法与机器人系统之间的闭环证据。

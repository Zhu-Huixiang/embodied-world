# CVPR｜IEEE/CVF Conference on Computer Vision and Pattern Recognition

## 这是什么刊会

计算机视觉、视觉表征、三维感知与图像/视频生成。

评审与出版：主会研究论文同行评审；正式主会论文集是本目录的归档依据。

## 含金量与领域定位

视觉领域主要主会；视觉动作论文能否执行，需要继续查机器人实验。

下面把目录事实、计量快照与编辑判断分开列出。核对日期：2026-10-10。

| 指标 | 本版记录 |
| --- | --- |
| CCF | A 类；2026目录，第57页 |
| JIF / SCI / 分区 | 会议不套用期刊影响因子、SCI或JCR/中科院分区 |
| 社区定位编辑分 | 95 / 100；编辑对领域定位的判断，非官方等级或口碑调查 |
| 本版刊会分 | 95.0 / 100；参与具身榜30%权重 |

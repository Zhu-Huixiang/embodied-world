# CoRL｜Conference on Robot Learning

## 这是什么刊会

机器人学习，连接机器学习方法、机器人数据、策略与真实系统。

评审与出版：主会研究论文同行评审；官方作者指南列出贡献、证据、复现与评审要求。

## 含金量与领域定位

机器人学习的专门会议，对策略、数据与泛化路线有直接参考价值。90是编辑判断，未冒充CCF等级。

下面把目录事实、计量快照与编辑判断分开列出。核对日期：2026-10-10。

| 指标 | 本版记录 |
| --- | --- |
| CCF | 2026目录全文未收录；按领域定位解释 |
| JIF / SCI / 分区 | 会议不套用期刊影响因子、SCI或JCR/中科院分区 |
| 社区定位编辑分 | 90 / 100；编辑对领域定位的判断，非官方等级或口碑调查 |
| 本版刊会分 | 90.0 / 100；参与具身榜30%权重 |

CoRL 主会与 workshop 分开；会议年份按举办年份，PMLR 卷的出版年份可能晚一年。

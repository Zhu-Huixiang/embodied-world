# 刊会含金量：简称、影响因子与“几区”怎样读

会议和期刊先分开。RSS、CoRL、ICRA 是机器人会议；ICLR、ICML、NeurIPS 是机器学习会议；CVPR、ICCV 是视觉会议。Nature 是综合科学期刊，Sci. Robot. 是 Science Robotics，TOG 是 ACM Transactions on Graphics。SIGGRAPH 是图形学会议，部分技术论文经 TOG 期刊路线发表；轨道须逐篇核对。

## CCF A / B / C 是什么

中国计算机学会按计算机研究领域给国际刊会的推荐分类；A、B、C是该目录的级别，覆盖面与机器人社区不完全重合。这里采用2026目录当前快照，不能据此说2018年发表时已是同一级别。ICLR在2026目录为A；RSS与CoRL未在核对的72页目录中找到，这不会自动使它们变成C类或零分。ICRA为B，同时是机器人领域覆盖广的主要会议。

## 影响因子 JIF 是什么

某指标年的引用，针对该刊此前两年发表的可引文献，形成的期刊层面统计。不同领域的引用习惯与文种有差异，JIF高低不能直接转换为单篇论文的质量。这里把2025指标年与2026发布年分开写。Nature的56.1由出版社页面核对；Science Robotics的25.5取自公开机构表，官方指标页访问受限；TOG的13.0由机构表与ACM官方新闻检索摘要交叉核对。

## SCI、JCR Q1和中科院1区有什么区别

SCIE是索引收录身份，不是“几区”。JCR将期刊放在具体学科里分成Q1–Q4，Q1通常对应前25%；多学科期刊可能有多个分区。中科院分区采用另一套学科和分区方法，1–4区不能与Q1–Q4直接互换。

本版三本期刊的SCIE、Q1来自公开机构JCR表，表中没有逐学科类别，故标Q1*；这是可追溯的次级资料快照。中科院分区待官方授权数据核对，保持空缺，不按刊名或JCR反推。

## 主会、workshop、oral / poster

Workshop有自己的征稿、评审与发表规则，不能借同年主会的等级加分。Oral、poster通常描述展示方式；journal extension是另一个版本，引用与发表记录分别核对。仅投稿或under review不获得目标刊会分，正式录用/出版后才进入具身榜刊会轴。

## 本仓怎样用这些信息

具身榜给刊会质量30%权重，其他70%仍来自机制、证据、引用与复用/阅读价值。会议用CCF与明确标注的社区编辑判断；期刊加入压缩后的JIF。社区分是本仓可讨论的判断，不是口碑调查或官方评定。所有计算见[具身榜评分说明](../leaderboard/methodology.md)，原始年份、来源与页面见[刊会资料表](profiles.json)。

# SIGGRAPH / TOG｜SIGGRAPH / ACM Transactions on Graphics

## 这是什么刊会

计算机图形学、视觉计算、动画与物理角色控制；角色控制可作为机器人动作先验的基础。

评审与出版：编辑筛选后进行同行评审；研究论文、评论和新闻等文章类型分别核对，不能仅凭刊名判断文种。

## 含金量与领域定位

图形学核心发表入口；物理角色控制里的先验、模仿和技能表征对具身控制有方法价值。

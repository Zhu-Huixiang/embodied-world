# NeurIPS D&B｜NeurIPS Datasets and Benchmarks Track

## 这是什么刊会

数据、评测与研究基础设施；机器人仿真平台在这一轨道归档。

评审与出版：NeurIPS Datasets and Benchmarks 独立轨道同行评审，有官方论文集。

## 含金量与领域定位

专门评审数据、基准和基础设施的贡献与可复用性；本仓给90分，不套用NeurIPS研究主会分。

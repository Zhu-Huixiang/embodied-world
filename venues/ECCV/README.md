# ECCV｜European Conference on Computer Vision

## 这是什么刊会

计算机视觉与机器学习，含视觉表示、三维重建和生成基础。

评审与出版：ECVA主办的双年视觉主会，研究论文同行评审，论文集由Springer出版。

## 含金量与领域定位

视觉领域主要主会之一，与CVPR、ICCV一起提供机器人感知和场景表示的重要基础。

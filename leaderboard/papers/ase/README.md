## 机制简析

将潜技能条件与对抗动作先验联合训练，再让高层策略选择可复用的技能嵌入。

带着这个问题读：连续技能潜变量怎样组织可重复使用的动作？

初读判断：可复用技能接口值得与机器人动作latent比较；初读分清训练奖励和高层控制。

## 机制简析

将多步扩散动作策略蒸馏为较少步的一致性策略，以减少推理步骤保留动作分布。

带着这个问题读：蒸馏怎样减少去噪步骤，保留怎样的动作分布？

初读判断：速度/成功率取舍明确；作为控制时钟的对照非常合适。

## 机制简析

联合建模未来视频与动作，将大规模视觉动态先验用于未见任务的闭环策略。

带着这个问题读：视频与动作共同预测，怎样支持未见任务中的控制？

初读判断：WAM零样本任务分歧清楚；初读仍要按数据、未见任务划分和控制时钟拆证据。

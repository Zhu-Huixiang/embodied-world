## 机制简析

微调视频基础模型，把动作、未来视觉状态和规划信号放进共同生成过程。

带着这个问题读：视频生成序列怎样容纳动作、未来状态与规划信号？

初读判断：视频先验到控制的接口值得看；精读需追训练条件和规划/策略消融。

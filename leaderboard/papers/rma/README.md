## 机制简析

训练利用特权环境信息的基础策略，部署用状态动作历史估计环境编码，在线适配腿足控制。

带着这个问题读：训练时的环境特权信息，怎样通过历史状态在部署时估计？

初读判断：特权信息到历史估计的接口影响大；适合追环境变化与适应延迟。

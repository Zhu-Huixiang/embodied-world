## 机制简析

以 POMDP/控制目标为入口，按像素、latent、粒子、关键点、物体中心表示比较动力学；再讨论感知和控制接口。

带着这个问题读：世界模型该预测像素、latent、粒子还是物体？换种表示会怎样改写感知与规划的代价？

初读判断：统一比较表达能力、样本效率、泛化和感知代价；不将引用的实验当成本综述自有实验。

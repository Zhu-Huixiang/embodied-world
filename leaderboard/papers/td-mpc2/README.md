## 机制简析

共享潜世界模型、价值和规划结构跨多任务学习，处理不同奖励尺度与动作空间。

带着这个问题读：多任务潜空间规划怎样处理不同动作空间和奖励尺度？

初读判断：大范围连续控制与复用实现有优势；重要的是任务配置和计算预算。

## 机制简析

以视频生成器的时空动态先验联合预测未来画面与机器人动作，考察未见操作泛化。

带着这个问题读：视频生成先验怎样与动作预测一起用于操作泛化？

初读判断：未来视觉与动作的对应关系值得拆；按正式NeurIPS原作范围阅读。

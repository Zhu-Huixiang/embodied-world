## 机制简析

让地形感知与本体反馈共同支持腿足策略，在复杂户外地形中考察感知失效和控制鲁棒性。

带着这个问题读：感知不可靠时，地形信息和本体反馈怎样共同支持行走？

初读判断：真实环境证据与感知鲁棒性突出；硬件复现成本较高。

## 机制简析

以统一的世界模型、奖励价值尺度处理和优化设计覆盖多类控制任务，减少逐任务调参。

带着这个问题读：跨任务尺度变化时，表征、价值和优化怎样保持可用？

初读判断：跨域控制证据充分，代码与训练配方利于复用；正式Nature版本单独计量。

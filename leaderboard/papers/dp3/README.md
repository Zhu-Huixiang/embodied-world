## 机制简析

以简洁点云编码器提供三维条件，用扩散生成动作，观察几何表示对泛化的影响。

带着这个问题读：简洁点云表示怎样改变操作策略的泛化？

初读判断：三维条件表示与动作生成分工容易拆；任务、点云处理与泛化协议需一起读。

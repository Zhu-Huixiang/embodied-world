## 机制简析

把机器人动作写成语言模型词表内的编号，将机器人示范与视觉语言任务共同训练以迁移网络语义。

带着这个问题读：文字和动作一起训练，网络知识怎样影响一次操作？

初读判断：把网络知识接入动作的早期路线；跨任务结果有启发，实施门槛较高。

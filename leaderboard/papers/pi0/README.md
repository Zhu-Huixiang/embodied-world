## 机制简析

视觉语言骨干提供语义条件，Flow Matching 动作专家生成连续动作块，再按闭环观测更新。

带着这个问题读：Flow Matching 动作专家怎样接收视觉语言条件？

初读判断：通用VLA与连续动作块的重要接口；适合逐项拆多本体数据和任务协议。

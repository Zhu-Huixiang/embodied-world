## 机制简析

把一段动作联合预测，条件变分自编码器吸收示范差异，时间集成融合重叠预测减轻误差积累。

带着这个问题读：Action chunking 与时间集成怎样处理示范中的误差累积？

初读判断：低成本双臂硬件与动作分块相互支撑，适合同时读数据系统和策略。

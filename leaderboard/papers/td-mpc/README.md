## 机制简析

学习用于奖励和值预测的潜动力学，结合短期模型预测控制与终端价值选择连续动作。

带着这个问题读：怎样学习足够用于控制的潜动力学，而省去图像重建？

初读判断：规划而不重建像素的任务相关表示值得对照Dreamer。

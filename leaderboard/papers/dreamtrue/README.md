## 机制简析

将动作轨迹渲染进图像条件并校准，改变轨迹生成反事实未来，再用人标视频缺陷训练奖励模型指导后训练。

带着这个问题读：模型怎样避免把每次接触都预测成成功？

初读判断：动作忠实性与失败覆盖形成清楚分歧；初读优先看校准、反事实和奖励各自的对照。

## 机制简析

DCT低频系数与四级残差码固定组长；缺失组监督连接人类/机器人数据，分组恢复接上重叠控制。

带着这个问题读：固定长度动作词表怎样同时连接跨来源数据和控制时钟？

初读判断：固定组长、跨来源有效损失与并行恢复的组合清楚；SIMPLE总分、难格子、消融和两项实机均已逐项读过；实现复用仍需后续跟进。

## 机制简析

把单视频压成顺序场景关系图，以图约束重置状态、阶段奖励，指导 RL 搜索更广的抓取与物体配置。

带着这个问题读：场景图怎样同时提供探索引导与不锁死姿态的泛化？

初读判断：单视频灵巧操作；摘要给出五项任务、对照与实机转移；优先检查重置采样和奖励消融。

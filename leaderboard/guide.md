# 具身榜：怎样筛选和继续读

[打开交互榜](https://zhu-huixiang.github.io/embodied-world/leaderboard/)

## 下载后打开

打开[index.html 文件页](index.html)，点击右上角 **Download raw file** 下载文件，用浏览器打开。筛选与排序可离线使用；论文链接需要联网。

## 组合筛选

| 想找什么 | 怎么填 |
| --- | --- |
| 排名前20，再看第40篇和60至80篇 | 排名填 `1-20,40,60-80` |
| 2021至2023和2025年的论文 | 年份填 `2021-2023,2025` |
| 至少80分 | 综合分填 `≥80`；也支持 `80-90,95.3`、`≤90` |
| 同时看RSS和CoRL | 刊会勾选RSS、CoRL |
| 世界模型或世界动作模型 | 方向勾选两个方向 |
| 名称包含Dreamer或LeWM | 简称填 `Dreamer,LeWM` |
| 想看某个作者、实验室或大学 | 出处关键词填 `Yanjie Ze,清华,Tsinghua`，或在团队/机构里勾选多个入口 |

同一栏多个值取并集，各栏条件同时满足。数字区间包含两端；留空表示全部。八个表头均可排序。综合分排序使用完整计算值，展示同分时保留实际先后，排名始终是全榜名次。

## 点进论文以后

- 简称：七维评分、透明雷达、逐项依据。
- 完整题目：已有精讲进入全文；其余进入机制导读、阅读问题与原文。
- 发表刊会：正式刊会集锦或arXiv集锦。
- 所属方向：论文地图的对应方向。
- 论文出处：首署名、已核通讯作者、署名机构与团队介绍；团队页汇总研究关注点、本仓论文和已核官方学术入口。

[作者与团队目录](origins/README.md)按本仓已收录工作汇总，大学与具体实验室分开，联合工作可归入多个介绍页。

**复制筛选链接**保留当前条件和排序。离线版分享链接带本机路径，分享时请发送HTML文件。**导出当前结果**得到包含论文出处的UTF-8 CSV，顺序与表格一致。手机可横向滑动表格查看其余列。

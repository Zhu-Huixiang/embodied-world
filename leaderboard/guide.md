# 具身榜：怎样筛选和继续读

[打开交互榜](https://zhu-huixiang.github.io/embodied-world/leaderboard/)

## 下载后打开

打开[index.html 文件页](index.html)，点击右上角 **Download raw file** 下载文件，用浏览器打开。筛选与排序可离线使用；论文链接需要联网。GitHub 的 Markdown 榜单保留全部跳转，筛选控件在交互页中使用。

## 组合筛选

| 想找什么 | 怎么填 |
| --- | --- |
| 排名前20，再看第40篇和60至80篇 | 排名填 `1-20,40,60-80` |
| 2021至2023和2025年的论文 | 年份填 `2021-2023,2025` |
| 80分至90分，或95.3分 | 综合分填 `80-90,95.3`；也支持 `≥80`、`≤90` |
| 同时看RSS和CoRL | 刊会勾选RSS、CoRL |
| 世界模型或世界动作模型，且总分至少80 | 方向勾选两个方向，综合分填 `≥80` |
| 名称包含Dreamer或LeWM | 简称填 `Dreamer,LeWM` |
| 题目包含world model或diffusion | 完整题目填 `world model,diffusion` |

同一栏多个值取并集，各栏条件同时满足。数字区间包含两端；留空表示全部。可点击任一表头，或在“排序依据”和“排序顺序”里选择。分数排序使用完整计算值，展示同分时也保留原榜先后。筛选后排名仍是全榜名次。

## 点进论文以后

- 简称：七维评分、透明雷达、逐项依据。
- 完整题目：已有精讲进入全文；其余进入机制导读、阅读问题与原文入口。
- 发表刊会：对应正式刊会集锦；预印本进入arXiv集锦。
- 所属方向：论文地图的具体方向，继续读同路线的论文。

**复制筛选链接**保留当前条件和排序，在线打开时可直接分享。离线版分享链接带本机路径，分享给别人时请发HTML文件，或等在线入口上线后再复制链接。**导出当前结果**得到UTF-8 CSV，顺序与当前表格一致。手机可横向滑动表格查看其余列。
